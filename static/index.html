    Chronicle & GTI REST API HTTP Methods Guide
    
            
    Essential guide to HTTP verbs, request types, and REST conventions
    
          
    
        
    
        
      
    

      
    
        
    
          
    
            
    
              GET
              Read / Retrieve Intelligence & Resources
            
    
            Safe & Idempotent • No Body
          
    
          
    
            Fetches Chronicle feeds/rules/cases or GTI file hash reports, threat scores, passive DNS records, and threat actor collections without modifying server state.
          
    
        
    

        
    
          
    
            
    
              POST
              Create / Scan / Execute Custom Action
            
    
            Mutating • JSON Body
          
    
          
    
            Creates new resources (Chronicle feeds/rules or GTI Threat Collections), triggers Chronicle :search queries, or submits URLs/files to GTI for live scanning.
          
    
        
    

        
    
          
    
            
    
              PATCH
              Partial Update / Modify
            
    
            Modifying • JSON Body
          
    
          
    
            Updates specific fields of an existing Chronicle feed/rule or modifies a GTI Threat Collection or Livehunt YARA ruleset.
          
    
        
    

        
    
          
    
            
    
              DELETE
              Remove / Destroy
            
    
            Destructive • Irreversible
          
    
          
    
            Permanently deletes a resource by ID (e.g., removing a Chronicle feed or deleting a custom GTI Threat Collection).
